# lantern-report

Turns graph paths plus decisions into findings, then findings into a DPIA (GDPR Art. 35, ICO template) and a CCPA/CPRA mapping.

**Inputs:** a serialized graph and its decisions.
**Outputs:** findings, diffs between runs, and reports in JSON, Markdown, HTML, and DOCX.

Status: skeleton. Implemented in Prompts 5 and 7.
